- **Royal Bridal Suite:** Dedicated packages for Gujarati and modern brides with sweat-proof 14-hour longevity, Panetar draping, and pre-bridal glow packages.
- **4.9★ Google Reviews:** Reputation showcase backed by 2,939+ verified reviews with breakdown and category filters.

## 🛠️ Tech Stack
- **Framework:** React 18, Vite
- **Routing:** React Router v7
- **Styling:** Tailwind CSS, PostCSS
- **Icons:** Lucide React
- **Celebration Animations:** Canvas Confetti

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
